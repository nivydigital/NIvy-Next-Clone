# P0.4 — Standard agent run path

**Date:** 2026-09-17  
**Status:** 🟢 Implemented (unified `/execute`)

## Target lifecycle

```
Receive → Validate → Authorize → Plan → Execute → Verify → Commit/Report → Audit
```

## Implemented path

`POST /api/v1/runtime/agents/{agent_id}/execute`

Request body (`AgentExecuteRequest`):
```json
{
  "payload": { "...": "agent input fields" },
  "prompt_id": null,
  "allow_llm_fallback": true,
  "request_id": optional
}
```

### Steps (`discovery.execute_agent`)

1. Resolve agent (registry or extension module on disk)
2. Load `agents/{id}/input.schema.json` and check **required** fields
3. Dynamic-import `backend.app.runtime.{a0xx}` and find `run_a0xx_*` coroutine
4. If found → call structured entrypoint; audit start/complete/fail
5. Else if `allow_llm_fallback` → `runtime_engine.run_llm` with bound prompt
6. Else fail closed (`RuntimeDenied`)
