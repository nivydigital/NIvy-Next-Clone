## Gaps

1. **Registry lag:** A003–A033 exist on disk as strategy-chain extensions but are **not** listed in canonical `agents/registry.yaml`.
2. **API lag:** Only A001–A005 have dedicated FastAPI routes. A034+ rely on generic `POST /api/v1/runtime/agents/{agent_id}/run` which calls `runtime_engine.run_llm` — **not** the structured `run_a0XX_*` entrypoints.
3. **Status lag:** Nearly all registry entries remain `status: declared`, `runtime: planned` even when folders + `backend/app/runtime/a0XX.py` exist.
4. **ID holes:** Registry intentionally skips some numbers (e.g. A040, A042) — folders may or may not exist; do not invent IDs.

## Recommendation

- Keep strategy A003–A033 as **extension** track OR add them to registry with provenance note.
- Add discovery endpoint listing registry agents + whether `runtime/a0XX.py` exists + whether dedicated route exists.
- Promote registry `runtime:` fields to real module paths when wiring is verified (Phase 0.3).
