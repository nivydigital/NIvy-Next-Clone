## Response includes

- registry status / in_registry
- agent folder exists
- runtime module path + exists
- structured_entrypoint name (if `run_a0xx_*` found)
- dedicated_route (A001–A005)
- tools / prompts / skills from registry
- input/output schema flags (+ full schema body on detail)
